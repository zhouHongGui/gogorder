# M10 - 门店端接单看板与制作核销

---

## 1. 概述

门店店员登录 Vue 3 管理后台后进入门店操作台，处理本店订单的接单→制作→核销全流程。店长和授权岗支持切换多家门店。

**所属端**：B端（Vue 3 + Vite 6）+ 后端

**优先级**：🔴 高 — M08 完成后即可开发

## 3. 设计逻辑

### 3.1 多门店上下文（对齐 M13）

- 登录后读取 `staff_shop`，`is_default=1` 为当前门店。
- 店长/管理员在顶部栏可切换门店 → 所有 B端接口追加 Header `X-Shop-Id`。
- 后端拦截器校验：当前用户 + 目标门店是否在 `staff_shop` 中存在。
- **越权防护**：每个接口校验 `staff_shop` 关联，禁止跨门店操作。

### 3.2 订单流转

```
order_status=1   order_status=2   order_status=3   order_status=4
(已支付/待接单) → (制作中)       → (待取餐)       → (已完成)
     │                │               │               ▲
     │ 店员接单        │ 制作完成      │ 核销取餐        │
     └────────────────►└──────────────►└───────────────┘
```

### 3.3 核销

- 扫码/手输 `pickup_token`（8位字母数字）。
- 展示号 `pickup_display`（5位数字）用于屏幕叫号。
- 核销校验：`pickup_token` 存在 + `order_status=3` + 归属本门店。
- 核销成功 → `order_status=4` + `verify_time`。

### 3.4 制作超时预警

制作时长超过15分钟（可配置），卡片红色边框 + "超时"标签提醒。

## 4. 接口定义

### 4.1 看板聚合接口

```
GET /api/b/order/board
Header: X-Shop-Id: {shopId}
```

响应：
```json
{
  "code": 200,
  "data": {
    "pending": [...],   // order_status=1
    "making": [...],    // order_status=2
    "waiting": [...]    // order_status=3
  }
}
```

### 4.2 操作接口

| 接口 | 方法 | 校验 |
|------|------|------|
| `/api/b/order/{id}/detail` | GET | 归属本门店 |
| `/api/b/order/{id}/accept` | PUT | order_status=1 |
| `/api/b/order/batch-accept` | PUT | 批量，同上 |
| `/api/b/order/{id}/complete-make` | PUT | order_status=2 |
| `/api/b/order/verify` | PUT | pickup_token + order_status=3 + 归属本店 |
| `/api/b/order/pending-count` | GET | 轮询用 |
| `/api/b/shop/status` | PUT | 店长权限 |
| `/api/b/shop/revenue-today` | GET | 本店 |
