## 4. 接口规范

### 4.1 URL 前缀

| 端 | 前缀 | 认证 |
|----|------|------|
| C端 | `/api/c/` | Bearer Token (JWT, 7天) |
| B端 | `/api/b/` | 若依 Token |
| 管理后台 | `/api/admin/` | 若依 Token |

### 4.2 统一响应

```json
{ "code": 200, "msg": "操作成功", "data": {} }
```

分页响应（对齐若依格式）：

```json
{ "code": 200, "msg": "查询成功", "rows": [], "total": 100 }
```

### 4.3 全局约定

| 约定 | 说明 |
|------|------|
| 金额 | 后端 int（分），前端转元 |
| 距离 | 米 |
| 时间 | `yyyy-MM-dd HH:mm:ss` |
| 布尔 | tinyint 0/1 |
| 删除 | 逻辑删除 `del_flag` |

## 5. B端多门店上下文

- 登录后读取 `staff_shop` 中 `is_default=1` 的门店作为当前门店。
- 店长/授权岗可在顶部栏切换门店，切换后所有接口追加 Header `X-Shop-Id`。
- 后端拦截器校验当前用户是否有该门店的操作权限。

## 6. 核心设计决策

| 决策 | 说明 |
|------|------|
| 余额支付 | 行级锁 + 乐观锁 + 幂等键，详见 M08 |
| 库存 | 条件 UPDATE 原子扣减 + 流水，详见 M08 |
| 订单状态 | 三字段拆分（M13） |
| 取餐码 | 双字段分离（M13） |
| 规格 optionId | 全局唯一不可变（M13） |
| 购物车并发 | Lua 脚本 / 分 Field（M13） |
| 门店删除 | 逻辑删除，保留历史引用（M13） |
