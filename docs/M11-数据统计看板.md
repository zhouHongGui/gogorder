# M11 - 数据统计看板

---

## 1. 概述

平台管理员查看全平台数据概览：今日指标、近7日趋势、门店排行。

**所属端**：管理后台（Vue 3 + Vite 6）+ 后端

**优先级**：🟢 低 — 所有业务模块完成后才有完整数据

| 编号 | 功能 |

## 3. 设计逻辑

### 3.1 今日概览

```sql
SELECT
  COUNT(*) AS order_count,
  COALESCE(SUM(total_amount), 0) AS revenue,
  COALESCE(SUM(total_amount) / NULLIF(COUNT(*), 0), 0) AS avg_amount,
  COUNT(DISTINCT shop_id) AS active_shops
FROM biz_order
WHERE DATE(pay_time) = CURDATE()
  AND pay_status = 1;
```

### 3.2 近7日趋势

按支付日期分组，统计 `pay_status=1` 的未退款订单数和营收。日期缺失填充 0。

### 3.3 门店排行

按今日营收降序 Top 10：
```sql
SELECT o.shop_id, s.name AS shop_name, COUNT(*) AS order_count, SUM(o.total_amount) AS revenue
FROM biz_order o
JOIN shop s ON s.id = o.shop_id
WHERE DATE(o.pay_time) = CURDATE() AND o.pay_status = 1
GROUP BY o.shop_id, s.name
ORDER BY revenue DESC
LIMIT 10;
```

### 3.4 monthly_sales 实时查询

商品月销量从 `biz_order_item` + `biz_order` 计算（近30天统计窗口）：
```sql
SELECT product_id, SUM(quantity) AS sales
FROM biz_order_item oi
JOIN biz_order o ON oi.order_id = o.id
WHERE o.shop_id = ? AND o.pay_time >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  AND o.pay_status = 1
GROUP BY product_id;
```
