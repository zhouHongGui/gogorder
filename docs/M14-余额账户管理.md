# M14 - 余额账户管理（管理后台）

---

## 1. 概述

管理员为 C 端用户查询余额、执行后台手动充值并查看余额流水。V1.0 C端无充值入口，余额账户管理是余额支付可用的前置模块。

**所属端**：管理后台（Vue 3 + Vite 6）+ 后端

**优先级**：🔴 高 — M08 余额支付的前置

---

## 2. 功能列表

| 编号 | 功能 |
|------|------|
| F01 | 按手机号/昵称查询用户余额 |
| F02 | 管理员手动充值 |
| F03 | 查询用户余额流水 |
| F04 | 充值操作审计与幂等防重 |

---

## 3. 设计逻辑

### 3.1 充值事务

1. 校验管理员具有 `gogorder:balance:recharge` 权限。
2. 校验充值金额大于0、备注必填、`requestId` 必填。
3. `SELECT c_user_balance ... FOR UPDATE` 锁定余额账户。
4. 增加余额并更新版本号。
5. 写入 `balance_ledger`：
   - `type=RECHARGE`
   - `amount` 为正数
   - 记录 `before_balance` / `after_balance`
   - `operator_id` 为当前管理员
   - `idempotent_key="recharge:{requestId}"`
   - `remark` 记录充值原因
6. 同一事务提交。

禁止通过通用 CRUD 或 SQL 页面直接修改 `c_user_balance.balance`。

### 3.2 幂等和审计

- 前端每次充值生成全局唯一 `requestId`。
- `balance_ledger.idempotent_key` 唯一约束防止重复充值。
- 充值记录不允许删除或修改。
- V1.0 不提供 C 端充值和提现。

---

## 4. 接口定义

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/admin/balance/list` | GET | 用户余额列表，支持手机号/昵称查询 |
| `/api/admin/balance/{userId}/recharge` | POST | 手动充值 |
| `/api/admin/balance/ledger` | GET | 余额流水列表 |

充值请求：

```json
{
  "amount": 5000,
  "requestId": "uuid",
  "remark": "线下收款充值"
}
```

## 7. 验收标准

- [ ] 首次注册用户具有余额为0的账户
- [ ] 有权限管理员可以充值，无权限用户返回403
- [ ] 充值同时更新余额并写入完整流水
- [ ] 重复 requestId 不会重复增加余额
- [ ] 流水记录包含操作人、充值原因和变更前后余额
- [ ] 禁止直接编辑余额和删除流水
