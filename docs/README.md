## 关键设计速查

| 主题 | 决策 | 详见 |
|------|------|------|
| 支付方式 | 余额支付 | M13 §8, M08 |
| 订单状态 | order_status / pay_status / refund_status 三拆分 | M13 §4 |
| 表名 | order → biz_order | M13 §3 |
| 库存 | 商品级，条件UPDATE原子扣减 + 幂等键 | M13 §9 |
| 取餐码 | pickup_token + pickup_display 双字段分离 | M13 §7 |
| 规格 | optionId 全局唯一不可变 | M13 §6 |
| 多分类 | product_category 关联表 | M13 §12 |
| 多门店员工 | staff_shop 关联表 + 当前门店上下文 | M13 §10 |
| 购物车 | shopId 必传，Lua脚本/Lua脚本防并发 | M13 §14 |
| 门店删除 | 逻辑删除，保留历史引用 | M13 §5 |
| 营业时间 | 支持跨午夜 | M13 §5 |
| monthly_sales | 实时查询近30天 | M13 §13 |
| H5登录 | 手机号短信，不依赖公众号 | M13 §11 |
| 小程序手机号 | 新版 phone code，与 login code 分离 | M13 §11 |
| 订单类型 | 即时单 / 预订单；休息和暂停门店仅允许预订单 | M13 §5.1 |
| 支付后流转 | 支付成功自动接单，用户不可取消 | M13 §4.4 |
| 退款 | 每单严格一次整单全额退款 | M13 §8.4 |
| 后台充值 | 仅通过余额账户管理事务充值并记录审计流水 | M14 |
