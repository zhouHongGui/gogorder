# M03 - 商品中心（管理后台）

---

## 1. 概述

平台管理员统一管理商品分类、规格模板、规格选项、商品库和门店商品分配。商品中心是 C端菜单的数据来源。

**所属端**：管理后台（Vue 3 + Vite 6）+ 后端

**优先级**：🔴 高 — M06 的前置

## 3. 设计逻辑

### 3.1 规格选项（对齐 M13）

- **optionId 不可变**：每个选项有全局唯一的 `option_id`（雪花ID/UUID），生成后永不改变。
- **选项不可物理删除（有历史引用时）**：若 `biz_order_item.specs` 引用了该 optionId → 仅可标记 `status=0`（禁用）。
- **可新增选项**：规格模板允许新增选项（新的 optionId）。
- **名称可修改**：label 可改，不影响历史（订单是快照）。
- **加价可修改**：priceAdd 可改，已有订单不受影响。
- 规格模板定义 `required`、`min_select`、`max_select`，后端下单时校验必选和多选数量范围。
- 单选规格最多只能有一个默认选项；多选默认选项数量不得超过 `max_select`。

### 3.2 商品多分类

- 商品通过 `product_category` 关联表支持多分类。
- `product_category.sort_order` 定义商品在指定分类下的排序。
- `uk_product_category` 防止重复关联。
- 删除分类 → 级联删除 `product_category` 记录。
- 删除商品 → 级联删除 `product_category` 记录。

### 3.3 门店商品库存

- 商品级库存：`shop_product.stock`，`-1` = 无限。
- 不支持 SKU 规格库存，不支持原料库存。
- 下单时条件 UPDATE 原子扣减；`-1` 不参与扣减并始终保持无限库存。
- 每次有限库存变更写入 `stock_ledger`，幂等键包含订单、门店商品和变更类型。

### 3.4 monthly_sales

- `shop_product.monthly_sales` 字段**移除**。
- C端展示的月销量从订单表实时查询（近30天已支付及之后的订单）。
- 可缓存到 Redis（日汇总），减少实时查询压力。

### 3.5 价格计算

```
最终单价 = shop_product.price（或product.base_price）
         + Σ 选中的 spec_option.price_add
```

后端根据 optionId 计算，不信任前端传来的价格。

## 4. 接口定义

### 4.1 商品分类

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/admin/category/list` | GET | 分类列表 |
| `/api/admin/category` | POST | 新增（name, sortOrder） |
| `/api/admin/category/{id}` | PUT | 编辑 |
| `/api/admin/category/{id}` | DELETE | 删除（级联 product_category） |

### 4.2 规格模板 + 选项

| 接口 | 方法 |
|------|------|
| `/api/admin/spec-template/list` | GET |
| `/api/admin/spec-template` | POST |
| `/api/admin/spec-template/{id}` | PUT |
| `/api/admin/spec-template/{id}` | DELETE |
| `/api/admin/spec-option/list?templateId=` | GET |
| `/api/admin/spec-option` | POST |
| `/api/admin/spec-option/{id}` | PUT（label/priceAdd 可改，option_id 不可改） |
| `/api/admin/spec-option/{id}/disable` | PUT（标记禁用，不清除数据） |

### 4.3 商品库

| 接口 | 方法 |
|------|------|
| `/api/admin/product/list` | GET（支持 categoryId 筛选） |
| `/api/admin/product/{id}` | GET（含 spec_template 详情 + 关联分类列表） |
| `/api/admin/product` | POST（含 categoryIds[]、specTemplateIds[]） |
| `/api/admin/product/{id}` | PUT |
| `/api/admin/product/{id}` | DELETE（校验无门店引用） |

### 4.4 门店商品

| 接口 | 方法 |
|------|------|
| `/api/admin/shop-product/list/{shopId}` | GET |
| `/api/admin/shop-product/assign` | POST（shopId + productIds[]） |
| `/api/admin/shop-product/{id}` | PUT（price/status/sortOrder，不直接修改库存） |
| `/api/admin/shop-product/{id}/stock-adjust` | POST（库存调整，requestId + stock + reason） |
| `/api/admin/shop-product/batch-remove` | DELETE |

## 5. 数据库表关联

| 表 | 关系 |
|----|------|
| category | 主表 |
| product_category | product_id + category_id → 多对多 |
| spec_template | 主表 |
| spec_option | template_id → spec_template.id |
| product | 主表 |
| shop_product | shop_id + product_id → 多对多关联 |
