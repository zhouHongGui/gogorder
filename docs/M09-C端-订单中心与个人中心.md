# M09 - C端订单中心与个人中心

---

## 1. 概述

C端用户查看订单列表、订单详情（含三状态 + 取餐码）、执行订单操作。个人中心展示余额和基础功能入口。

**所属端**：C端（uni-app）+ 后端

**优先级**：🟡 中 — 依赖 M08 先完成

## 3. 设计逻辑

### 3.1 订单状态与操作（对齐 M13）

| order_status | C端标签 | 可操作 |
|-------------|---------|--------|
| 0 | 待支付 | 去支付、取消 |
| 1 | 已接单/待制作 | — |
| 2 | 制作中 | — |
| 3 | 待取餐 | 查看取餐码 |
| 4 | 已完成 | 再来一单 |
| 5 | 已取消 | 再来一单 |

### 3.2 取餐码展示（对齐 M13）

- **pickup_token**：转二维码，用于门店扫码核销。
- **pickup_display**：大字展示，用于用户看叫号屏/听叫号。
- 仅在 `order_status=3` 时展示。
- 预订单额外展示 `scheduledPickupTime`。

### 3.3 取消规则

- 用户仅可取消自己的待支付订单（`order_status=0, pay_status=0`）。
- 支付成功即自动接单，用户端不再展示取消入口。
- 已支付订单如无法履约，由管理员或门店执行一次整单全额退款。

### 3.4 再来一单

- 将 `biz_order_item` 中的商品+规格（含 optionId）重新加入购物车。
- 使用当前最新价格。
- 已下架商品跳过并提示。
- 购物车 shopId 不一致时弹窗询问用户。

### 3.5 个人中心

- 顶部展示头像 + 昵称 + 手机号。
- **余额展示**：调用 `/api/c/user/balance` 获取当前余额。新用户默认为 0。V1.0 C端无充值入口（由管理员后台操作）。
- 入口：我的订单、余额明细（流水列表）、设置。

## 4. 接口定义

### 4.1 订单列表

```
GET /api/c/order/list?dateScope=TODAY&pageNum=1&pageSize=10
```

dateScope：`TODAY`=当日订单，`HISTORY`=历史订单。列表不按状态筛选，点击订单进入详情页查看状态与操作。

### 4.2 订单详情

```
GET /api/c/order/{id}
```

响应包含：订单类型、预约取餐时间、三状态字段、时间线、明细、取餐码（token+display）。

### 4.3 再来一单

```
POST /api/c/order/repurchase/{id}
```

### 4.4 余额查询

```
GET /api/c/user/balance
Response: { "balance": 50000 }
```
