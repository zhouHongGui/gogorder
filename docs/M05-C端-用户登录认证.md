# M05 - C端用户登录认证

---

## 1. 概述

C端用户登录，支持**小程序微信登录**和**H5短信验证码登录**。手机号为账号核心标识，微信身份存入独立绑定表。

**所属端**：C端（uni-app）+ 后端

**优先级**：🔴 高 — 所有C端功能的前置

---

## 2. 功能列表

| 编号 | 功能 | 端 |
|------|------|-----|
| F01 | 小程序微信登录（新版 phone code） | 小程序 |
| F02 | H5 短信验证码登录 | H5 |
| F03 | 发送短信验证码 | H5 |
| F04 | 用户信息查询/更新 | 双端 |

## 3. 设计逻辑

### 3.1 小程序登录（新版）

- `uni.login` 获取 **login code** → 后端换 openid。
- 前端 `<button open-type="getPhoneNumber">` 获取 **phone code** → 后端调用 `getPhoneNumber` 接口解密手机号。
- **login code 与 phone code 分开传递**，不可混用。
- 流程：
  1. 前端：`uni.login` → 得到 login code
  2. 前端：`POST /api/c/auth/login-by-wechat`（传 login code）
  3. 后端：code → openid → 查找 `c_user_wechat`；未绑定时返回一次性 `bindTicket`
  4. 前端：用户点击授权手机号 → `getPhoneNumber` → 得到 phone code
  5. 前端：`POST /api/c/auth/bind-phone`（传 bindTicket + phone code）
  6. 后端：校验 bindTicket 并取得 openid → phone code 解密手机号 → 手机号查找/创建 c_user → 绑定 wechat 身份 → 返回 Token

### 3.2 H5 登录

- 手机号 + 短信验证码。
- 不依赖微信公众号 openid/JSAPI。
- 验证码：6位数字，5分钟有效，60秒间隔，每日每手机号10次上限。

### 3.3 账号统一

- 核心标识：**手机号**。
- 同一手机号在小程序和 H5 登录 → 同一 c_user.id。
- 微信身份存入 `c_user_wechat`（独立表）。
- 首次登录自动注册，并在同一事务创建余额为0的 `c_user_balance`；已存在则复用。

### 3.4 Token

- JWT，payload：userId + phone
- 有效期：7天
- Header：`Authorization: Bearer {token}`

## 4. 接口定义

### 4.1 小程序登录（获取 openid 绑定状态）

```
POST /api/c/auth/login-by-wechat
Body: { "code": "login code from uni.login" }
Response: { "bound": true/false, "token": "..." (if already bound), "bindTicket": "..." (if unbound) }
```

### 4.2 小程序绑定手机号

```
POST /api/c/auth/bind-phone
Body: { "bindTicket": "one-time ticket", "phoneCode": "phone code from getPhoneNumber" }
Response: { "token": "...", "userInfo": {...} }
```

### 4.3 H5 发送验证码

```
POST /api/c/auth/send-sms
Body: { "phone": "13800001111" }
```

### 4.4 H5 验证码登录

```
POST /api/c/auth/login-by-sms
Body: { "phone": "13800001111", "code": "123456" }
Response: { "token": "...", "userInfo": {...} }
```

### 4.5 获取/更新用户信息

```
GET /api/c/user/info
PUT /api/c/user/update
Body: { "nickname": "...", "avatar": "..." }
```

## 5. 安全

| 防护点 | 措施 |
|--------|------|
| 验证码爆破 | 每手机号每日10次，每IP每日50次 |
| 短信轰炸 | 60秒间隔，Redis 限制 |
| Token 伪造 | JWT 签名 + 过期校验 |
| login code 重放 | 使用后标记失效 |
| bindTicket 冒用/重放 | Redis 存储，5分钟有效，绑定成功后立即删除 |
