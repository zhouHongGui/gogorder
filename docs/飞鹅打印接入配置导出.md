## 1. 飞鹅平台账号配置

### 1.1 配置结构（文档版，已脱敏）

```yaml
# 飞鹅打印机
feie:
  config:
    user: ${FEIE_USER}           # 飞鹅开发者账号（邮箱），向管理员索取，勿写入公开文档
    uKey: ${FEIE_UKEY}           # 飞鹅开发者 UKEY，敏感密钥，禁止提交 Git
    url: https://api.feieyun.cn/Api/Open/
```

| 字段 | 说明 | 可否写入本文档 / Git |
|------|------|----------------------|
| `user` | 飞鹅云后台注册的开发者账号（邮箱） | 建议脱敏，用占位符 |
| `uKey` | 飞鹅云后台「开发者信息」中的 UKEY | **禁止**，等同 API 密钥 |
| `url` | 飞鹅开放 API 地址 | 可以公开 |

### 1.2 真实配置获取方式

真实 `user` / `uKey` 由运维或项目负责人通过**私密渠道**提供，例如：

- 环境变量（`FEIE_USER`、`FEIE_UKEY`）
- 配置中心（Nacos / Apollo 等）
- 内部密码管理器或 IM（勿发公开群、勿提交仓库）

原项目配置位于 `application-dev.yml` / `application-test.yml` / `application-prod.yml` 的 `feie.config` 节点，**请勿将真实值抄入本文档**。

## 2. 敏感配置与安全说明

### 2.1 哪些配置不能泄露

| 配置项 | 敏感程度 | 泄露后果 |
|--------|----------|----------|
| **`feie.config.uKey`** | **高** | 配合 `user` 可代调用飞鹅 API：绑定/删除打印机、打印、查队列等 |
| `feie.config.user` | 中 | 暴露开发者账号身份 |
| 打印机 `sn` + `key`（设备密钥） | 高 | 可将打印机绑定到其他开发者账号（若未绑满） |
| `feie.config.url` | 无 | 公开地址，可写入文档 |

> **区分两个「key」：**  
> - `uKey` = 飞鹅**开发者**密钥（平台级，本文档重点保护对象）  
> - 打印机 `key` = 设备底部识别码（每台打印机不同，存业务库，同样不可公开）

### 2.2 不同场景下的处理方式

| 场景 | 建议 |
|------|------|
| 本文档提交 Git / 团队外分享 | 仅保留占位符（见第 1.1 节），**不得出现真实 `uKey`** |
| 私下交给 Codex 接内部项目 | 可通过环境变量或私密消息单独提供 `user`/`uKey`，不要写进 md |
| 两个项目共用同一飞鹅账号 | 另一项目部署时注入相同 `user`/`uKey`，仍不进仓库 |
| 打印机设备凭证 | `sn`/`key` 存数据库，由业务接口管理，不写入本文档 |

### 2.3 若 `uKey` 已泄露

1. 登录 [飞鹅开发者后台](https://admin.feieyun.com/) → 个人中心  
2. 重置 UKEY（若平台支持）或联系飞鹅客服  
3. 更新所有环境（dev / test / prod）的配置  
4. 检查飞鹅后台是否有异常打印机绑定或打印记录  

### 2.4 本文档可安全分享的内容

以下内容不含密钥，可交给 Codex 或外部协作者：

- 配置**结构**与字段说明（第 1 节）
- HTTP 签名规则、API 映射、打印格式（第 3～5 节）
- 实现指南与 Prompt 模板（第 8～9 节）
- 飞鹅官方文档与 Demo 链接（第 10 节）

## 4. HTTP 请求规范

### 4.1 签名规则

```
stime = 当前 Unix 时间戳（秒，10 位）
sig   = SHA1(user + uKey + stime)   // 40 位小写十六进制
```

Java 示例：

```java
String stime = String.valueOf(System.currentTimeMillis() / 1000);
String sig = DigestUtils.sha1Hex(user + uKey + stime);
```

### 4.2 请求方式

- 方法：`POST`
- Content-Type：`application/x-www-form-urlencoded`
- 地址：`https://api.feieyun.cn/Api/Open/`（统一入口，原项目使用此地址）

每次请求必带公共参数：

| 参数 | 说明 |
|------|------|
| `user` | 开发者账号 |
| `stime` | 时间戳（秒） |
| `sig` | 签名 |
| `apiname` | 接口名称 |

> 飞鹅平台正在将接口分流到独立 URL（如 `https://api.feieyun.cn/Api/Open/printMsg`）。统一入口目前仍可用，以[官方文档](http://www.feieyun.com/open/apidoc-cn.html)最新说明为准。

### 4.3 统一返回结构

```json
{
  "ret": 0,
  "msg": "ok",
  "data": {},
  "serverExecutedTime": 123
}
```

- `ret = 0` 表示成功
- 打印机状态 `data` 为字符串，常见值：
  - `离线。`
  - `在线，工作状态正常。`
  - `在线，工作状态不正常。`（常见原因：缺纸）

## 5. 飞鹅 API 映射表

| 业务 | apiname | 额外参数 |
|------|---------|----------|
| 批量添加打印机 | `Open_printerAddlist` | `printerContent` |
| 批量删除打印机 | `Open_printerDelList` | `snlist` |
| 修改打印机备注 | `Open_printerEdit` | `sn`, `name` |
| 清空待打印队列 | `Open_delPrinterSqs` | `sn` |
| 查询打印订单状态 | `Open_queryOrderState` | `orderid` |
| 查询某天打印数量 | `Open_queryOrderInfoByDate` | `sn`, `date`（yyyy-MM-dd） |
| 查询打印机状态 | `Open_queryPrinterStatus` | `sn` |
| 小票打印 | `Open_printMsg` | `sn`, `content`, `times`（可选） |
| 标签打印 | `Open_printLabelMsg` | `sn`, `content`, `times`（可选） |

### 5.1 添加打印机

```
printerContent = sn#key#备注名称#
```

多台换行分隔，每次最多 100 台（示例为虚构数据）：

```
960205660#your_device_key#门店A#
960205661#your_device_key#门店B#
```

若返回 `已被添加过`，可调用 `Open_printerEdit` 更新备注，视为绑定成功。

### 5.2 设备校验规则

- `sn`：飞鹅打印机编号为**纯数字**
- `key`：打印机底部密钥，由**数字、字母、下划线**组成
- 注意：`uKey`（开发者密钥）≠ 打印机 `key`

## 6. 打印内容格式

### 6.1 标签打印（label）

标签机使用 XML 标签语法：

```xml
<SIZE>40,30</SIZE>
<TEXT x="10" y="10">测试内容</TEXT>
<LOGO x="10" y="40">
```

| 标签 | 说明 |
|------|------|
| `<SIZE>宽,高</SIZE>` | 纸张尺寸（mm） |
| `<TEXT x="10" y="10">文字</TEXT>` | 文本 |
| `<LOGO x="10" y="40">` | 引用已设置的 LOGO |
| `<QR x="10" y="80">内容</QR>` | 二维码 |

请求示例（`apiname=Open_printLabelMsg`）：

| 参数 | 值 |
|------|-----|
| `sn` | 打印机编号 |
| `content` | 上述 XML 字符串 |
| `times` | `1`（打印份数，可选） |

### 6.2 小票打印（msg）

`apiname=Open_printMsg`，`content` 支持飞鹅小票排版指令（加粗、居中、切纸等），详见[官方文档](http://www.feieyun.com/open/apidoc-cn.html)。

### 6.3 标签机 LOGO 初始化（可选）

原项目有「初始化标签机 + 上传 BMP LOGO」逻辑，**不在本文档范围内**。若另一项目需要，Codex 须自行实现 `multipart/form-data` 上传（`logo` 字段，BMP 格式），参考官方文档；不是接入打印的必选项。

## 7. 打印机业务数据（新项目自行建表）

每台打印机除平台 `user`/`uKey` 外，还有设备级凭证，建议在新项目数据库中存储：

| 字段 | 类型 | 说明 |
|------|------|------|
| `sn` | string | 打印机编号 |
| `key` | string | 打印机密钥（设备级，敏感，勿写入文档） |
| `print_type` | string | `label` 标签机 / `msg` 票据机 |
| `print_width` | int | 纸宽 mm，如 `40` |
| `print_height` | int | 纸高 mm，如 `30` |
| `status` | int | `1` 启用 / `0` 停用 |

门店绑定、订单渠道等字段按新业务自行设计，**不必**照搬原项目 `shop_printer` 表。

---

## 8. 共用同一飞鹅账号

若两个项目使用**相同的 `user` / `uKey`**：

- 已在原项目绑定过的打印机，新项目可直接调用打印接口，无需重复绑定。
- 打印队列、状态查询在同一开发者账号下共享。

若使用**不同的飞鹅账号**：

- 需在新账号下重新执行 `Open_printerAddlist`。
- 一台物理打印机同一时间只能绑定一个开发者账号（最多 3 个账户，见官方文档）。

## 9. Codex 实现指南

### 9.1 建议实现的类

```
feie/
├── config/FeieProperties.java       # 读取 feie.config
├── client/FeieClient.java           # 签名 + HTTP POST
├── dto/FeieResponse.java            # ret/msg/data
└── service/FeiePrintService.java    # 业务封装
```

### 9.2 Maven 依赖（新项目）

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
<dependency>
    <groupId>commons-codec</groupId>
    <artifactId>commons-codec</artifactId>
</dependency>
<!-- 二选一 HTTP 客户端 -->
<dependency>
    <groupId>org.apache.httpcomponents.client5</groupId>
    <artifactId>httpclient5</artifactId>
</dependency>
<!-- 或 -->
<dependency>
    <groupId>com.squareup.okhttp3</groupId>
    <artifactId>okhttp</artifactId>
</dependency>
```

### 9.3 最小接入步骤

1. 通过环境变量配置 `feie.config`（第 1 节，**真实 uKey 不进仓库**）
2. 实现 `FeieClient`：公共参数 + 签名 + 表单 POST
3. 实现 `addPrinter`、`printLabel`、`printMsg`、`queryPrinterStatus`
4. 新建打印机表，存储 `sn` / `key`
5. 新增打印机时调用 `Open_printerAddlist` 绑定到开发者账号
6. 编写测试接口验证打印

### 9.4 官方参考代码

官方 Java Demo（单文件，可直接参考方法签名与参数）：

https://github.com/feiejishu/API_JAVA/blob/master/Api_java_demo.java

核心模式（添加打印机）：

```java
// 公共参数
params.put("user", USER);
params.put("stime", STIME);
params.put("sig", DigestUtils.sha1Hex(USER + UKEY + STIME));
params.put("apiname", "Open_printerAddlist");
// 业务参数
params.put("printerContent", "sn#key#备注#");
// POST application/x-www-form-urlencoded 到 url
```
