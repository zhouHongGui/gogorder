# M07 - C端购物车

---

## 1. 概述

C端用户将商品（含规格）加入购物车，支持修改数量和删除。购物车存储在 Redis，与门店绑定。

**所属端**：C端（uni-app）+ 后端

**优先级**：🔴 高 — M08 的前置

---

## 2. 功能列表

| 编号 | 功能 |
|------|------|
| F01 | 加入购物车（必须携带 shopId） |
| F02 | 查看购物车 |
| F03 | 修改数量 / 删除条目 |
| F04 | 清空购物车 |
| F05 | 切换门店处理 |

## 3. 设计逻辑

### 3.1 shopId 必传（对齐 M13）

加入购物车接口**必须携带 shopId**：

```
POST /api/c/cart/add
Body: { "shopId": 1, "productId": 10, "specs": {...}, "quantity": 1 }
```

**门店不一致处理**：
- 若 Redis 中现有 `shopId` 与新传入的不一致 → 返回错误码 `SHOP_MISMATCH` + 现有 shopName。
- **不清空购物车**。由前端弹窗询问用户是否切换并主动调清空接口。

### 3.2 规格传递（optionId）

```json
{
  "specs": {
    "1": "opt_def456",
    "2": "opt_ghi001",
    "3": "opt_jkl002",
    "5": ["opt_mno003", "opt_pqr004"]
  }
}
```

后端根据 optionId 查询 `spec_option` 表计算实际价格。**不信任前端传来的任何价格**。

### 3.3 并发方案（Lua 脚本）

购物车每个条目使用独立 Hash Field。`cartItemId` 使用 `productId + 规范化后的 specs` 计算稳定哈希，相同商品规格会命中同一 Field。添加/修改通过 Lua 脚本原子操作：

```lua
-- 原子添加购物车条目
local cartKey = KEYS[1]
local shopId = ARGV[1]
local itemField = ARGV[2]
local itemJson = ARGV[3]

local currentShopId = redis.call('HGET', cartKey, 'shopId')
if currentShopId and currentShopId ~= shopId then
    return {err = "SHOP_MISMATCH", currentShop = redis.call('HGET', cartKey, 'shopName')}
end
redis.call('HSET', cartKey, 'shopId', shopId)
local existing = redis.call('HGET', cartKey, itemField)
if existing then
    local oldItem = cjson.decode(existing)
    local newItem = cjson.decode(itemJson)
    oldItem.quantity = oldItem.quantity + newItem.quantity
    redis.call('HSET', cartKey, itemField, cjson.encode(oldItem))
else
    redis.call('HSET', cartKey, itemField, itemJson)
end
redis.call('EXPIRE', cartKey, 604800)
return {ok = "SUCCESS"}
```

### 3.4 相同商品判定

`productId` + 完全相同的 `specs`（optionId 组合相同）→ 合并数量。

`specs` 生成哈希前必须按 templateId 和 optionId 排序并规范化，避免同一组合因 JSON 键顺序不同生成不同条目。

### 3.5 Redis 结构

```
Key: cart:{userId}
Fields:
  shopId   → "1"
  shopName → "GoGo茶·天河店"
  item:{cartItemId} → JSON of single item
  version  → "1"（乐观锁版本号，全量替换时用）
```

## 4. 接口定义

| 接口 | 方法 | 关键参数 |
|------|------|----------|
| `/api/c/cart/get` | GET | — |
| `/api/c/cart/add` | POST | `shopId`(必填), `productId`, `specs`(optionId格式), `quantity` |
| `/api/c/cart/update` | PUT | `cartItemId`, `quantity` |
| `/api/c/cart/remove/{cartItemId}` | DELETE | — |
| `/api/c/cart/clear?shopId=` | DELETE | shopId 可选（切换门店用） |

### 加入购物车响应

```json
{
  "code": 200,
  "data": {
    "shopId": 1,
    "shopName": "GoGo茶·天河店",
    "items": [...],
    "totalAmount": 6200,
    "totalCount": 3
  }
}
```

### SHOP_MISMATCH 错误响应

```json
{
  "code": 409,
  "msg": "购物车中有其他门店的商品",
  "data": {
    "errorCode": "SHOP_MISMATCH",
    "currentShopName": "GoGo茶·越秀店"
  }
}
```
