# M02 - 门店管理（管理后台）

---

## 1. 概述

平台管理员管理所有门店信息。门店数据是系统的基石——C端选店、商品分配、订单归属均依赖门店。

**所属端**：管理后台（Vue 3 + Vite 6）+ 后端（Java 21 / SB 4.0.3）

**优先级**：🔴 高 — M03/M06 的前置

## 3. 设计逻辑

### 3.1 门店状态（对齐 M13）

| 值 | 状态 | C端可浏览菜单 | 即时单 | 预订单 |
|----|------|---------------|--------|--------|
| 0 | RESTING 休息中 | ✅ | ❌ | ✅ |
| 1 | OPEN 营业中 | ✅ | ✅ | ✅ |
| 2 | PAUSED 暂停接单 | ✅ | ❌ | ✅ |

所有未删除门店均可进入并浏览菜单。仅 `OPEN` 可提交即时单；`RESTING`、`PAUSED` 只能提交预订单。

### 3.2 营业时间跨午夜

`open_time > close_time` 表示跨日营业（如 18:00–02:00）。

后端判断"当前是否在营业时间内"逻辑：
```
if (open_time <= close_time):
    now >= open_time AND now <= close_time
else:
    now >= open_time OR now <= close_time
```

### 3.3 逻辑删除

- `del_flag = 1` 即删除。
- 删除前校验：该门店无 `order_status IN (0,1,2,3)` 的进行中订单。
- 删除后历史订单引用保留（不级联删除）。
- 禁止物理删除。

### 3.4 员工-门店关联

- 创建店员时自动在 `staff_shop` 插入一条记录（`is_default=1`）。
- 店长可被关联多家门店。
- 门店详情页展示已关联员工列表。

## 4. 接口定义

### 4.1 门店列表

```
GET /api/admin/shop/list
```

参数：`pageNum`, `pageSize`, `name`, `phone`, `status`

响应（若依分页格式）：
```json
{
  "code": 200,
  "rows": [
    {
      "id": 1, "shopCode": "GOG001", "name": "GoGo茶·天河店",
      "phone": "13800001111", "province": "广东省", "city": "广州市",
      "district": "天河区", "address": "体育西路123号",
      "longitude": 113.3211, "latitude": 23.1255,
      "openTime": "10:00", "closeTime": "22:00",
      "status": 1, "delFlag": 0, "packFee": 100,
      "createTime": "2026-06-01 10:00:00"
    }
  ],
  "total": 5
}
```

### 4.2 新增门店

```
POST /api/admin/shop
```

Body：`shopCode`(必填+唯一), `name`, `phone`, `province/city/district`, `address`, `longitude`, `latitude`, `openTime`, `closeTime`, `preorderMinMinutes`, `preorderMaxDays`, `makeLeadMinutes`, `packFee`, `sortOrder`, `notice`, `image`

### 4.3 编辑门店

```
PUT /api/admin/shop/{id}
```

Body：同新增（`shopCode` 不可修改）。

### 4.4 切换状态

```
PUT /api/admin/shop/{id}/status
Body: { "status": 0 }
```

### 4.5 删除门店

```
DELETE /api/admin/shop/{id}
```

校验进行中订单 → 设置 `del_flag=1`。

### 4.6 员工-门店关联

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/admin/shop/{id}/staff` | GET | 门店关联员工列表 |
| `/api/admin/shop/{id}/staff` | POST | 关联员工并设置岗位 |
| `/api/admin/shop/{id}/staff/{userId}` | PUT | 修改岗位/设为默认门店 |
| `/api/admin/shop/{id}/staff/{userId}` | DELETE | 移除关联 |

- 每个用户最多只有一个 `is_default=1` 的门店。
- 删除默认门店关联前，必须先指定新的默认门店；若员工仅关联一家门店则可直接移除。
- B端操作权限除校验关联关系外，还必须校验岗位所需权限。
